Biography

I am a master's student in Computer Science and Technology at the University of Science and Technology of China. I received my bachelor's degree from Huazhong University of Science and Technology in 2025, where I studied in the Computer Science Excellence Program.

My research focuses on efficient AI infrastructure. I work on GPU memory management, LLM inference systems, and scheduling for cloud services, with an interest in making resource-intensive workloads more practical to deploy.

Research Projects

  • GPU memory deduplication for serverless LLM inference (2025)

    Designed a driver-layer framework for sharing GPU memory across inference instances using CUDA virtual memory management, NVLink, and copy-on-write. In a four-A100 evaluation, it reduced GPU memory use by about 50% and doubled throughput in a resource-constrained setting.

  • Hybrid inference for resource-constrained systems (2024–2025)

    Built a hardware-aware prefill pipeline and CPU–GPU decode strategy on llama.cpp. End-to-end performance improved by up to 3.7 times compared with llama.cpp in the evaluated settings.

  • Cloud disk workload prediction and scheduling (2023–2024)

    Studied cloud block storage write patterns and developed workload-aware scheduling strategies for periodic and bursty traffic.
