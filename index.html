02 / Selected research

Work that moves the system forward.

Projects spanning GPU memory, hybrid inference, and cloud resource scheduling.

GPU systems / 202501

GPU memory deduplication for serverless LLM inference

A driver-layer framework that shares GPU memory across instances and inference frameworks using CUDA virtual memory management, NVLink, and copy-on-write techniques.

Result: Approximately 50% less GPU memory use and up to 2× throughput in a resource-constrained setting on four A100 GPUs.

CUDA VMMNVLinkServerless LLM
Inference systems / 2024–202502

Hybrid inference for limited resources

A hardware-aware prefill pipeline and CPU–GPU decode strategy built on llama.cpp to make efficient use of constrained hardware.

Result: Up to 3.7× end-to-end performance versus llama.cpp across the evaluated input lengths.

Prefill / DecodeCPU–GPU
Cloud storage / 2023–202403

Cloud disk workload prediction & scheduling

Analyzed write traffic patterns and designed workload-aware scheduling strategies for cloud block storage, including bursty batch workloads.
